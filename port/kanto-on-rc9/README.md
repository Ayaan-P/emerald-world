# Historical RC9 overlay

This directory preserves the earlier RC9 story-entry checkpoint from app PR #241. Do not apply this patch to RC10 or to the published Kanto engine.

The current supported draft source is the pinned native branch documented in `port/kanto-on-rc10/README.md`. Its changes include the trainer, encounter, travel and region-identity integration that supersedes this old patch.

The original manifest and patch remain unchanged for historical reconstruction. They are not the source used by this branch's build wrapper.
