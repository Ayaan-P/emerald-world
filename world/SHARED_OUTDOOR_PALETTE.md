# Shared outdoor terrain (experimental draft)

This paired app/native change adds an opt-in `world.create_painted_landscape` capability. It accepts the same `label`, `layout` and `blueprint` as `world.create_landscape`, plus `paint`, a JSON list of ordered rectangles with `x`, `y`, `width`, `height` and `terrain`. Terrain choices are `grass`, `tall_grass`, `long_grass`, `sand`, `water` and `rock`. The agent's entire tool step must fit the existing 1,024-character limit, so it may need a compact layout and few rectangles. Later rectangles win. The original capability and maps stay unchanged.

Existing Expansion General tiles render the palette; no new artwork is generated. Sand and grass are walkable, while rock and water are impassable. Both app and native check a closed boundary, connected walkable geometry and protected entrance/exit before admission. This cannot yet place trees, buildings, water traversal, elevation or actual new biomes. Painted areas are immutable shared destinations, and older operations that only support plain XL maps continue to reject them rather than silently dropping their colors.

`EWGMAP1A` is a new format, distinct from the existing offline `EWGMAP0D`. Its digest includes all palette bytes. `CAVE17`/`XLPAINT` capability negotiation means older clients do not receive the new format. A new client can retry CAVE16 with an older authority. The authority will not switch an occupied generated area. A mismatched currently occupied native area cannot be overwritten. Player saves and parties stay independent, and no existing world is silently changed. Owner archive previews currently show walkable geometry rather than a color-accurate preview.

Native pair: Ayaan-P/pokeemerald-expansion-native#149, commit 13192c4565cfb156a10b97377596264986ef880e, stacked on #148. The app manifest and gitlink pin that commit. The asset catalog metadata is repinned because the native changes affect only generated-map, bridge, wire and tests, not any catalog input. Full linked build, rendered play, real two-machine multiplayer and live agent use remain unverified. Do not treat this draft as a release.
