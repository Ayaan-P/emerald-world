# Private canonical relationship continuity

The existing Wally, Briney, Rydel and Steven conversation bindings can retain a
bounded, save-specific character perspective across private reflections. This is
an actor's tentative interpretation, not a numeric friendship score or a fact
about the player. No native story battle, item, service or scene is replaced.

The player still controls the existing private-memory and reflection workflow.
The reflection preview includes the prior perspective, the current explicit
conversation choice and acknowledged dialogue. It explains that the new
perspective will be retained if its reply is shown. Only that previewed summary
is sent to the already host-configured private worker. No new background model
service, public author access or automatic sending is introduced.

A generated answer alone does not update relationship memory. The exact native
display receipt must be acknowledged while the matching reflection is still
current. A replacement request, changed context, withdrawal or stale receipt
cannot install the old interpretation. The perspective and encounter summary
commit together. The next explicitly requested reflection can build on or revise
that prior perspective; its output replaces the old bounded 240-character note,
not an ever-growing transcript. Display acknowledgment is client attestation,
not proof of attention, agreement, affection or achievement.

Memory is keyed by authenticated trainer, save lineage and canonical actor.
The existing `memory` command shows only the active save's perspective, labelled
as tentative. Other trainers/saves do not receive it. It survives restart and
is pruned with the existing sixteen encounter profiles. `remember off` stops
new retention and model work; `forget` erases perspectives, choices and summaries.
Shared inspection and public world history remain unchanged. Host storage is
still host-accessible, as disclosed in the existing preview.

Tests exercise real authority private-worker claim/finish, native response and
display acknowledgment, two successive interpretations, restart, two saves,
another trainer, stale replacement and withdrawal. Author replies are deterministic
fixtures. Full native rendering, live model quality and integrated release remain
Maya's QA responsibilities. This is durable personal continuity, not autonomous
canonical travel or a replacement for normal Emerald progression.
