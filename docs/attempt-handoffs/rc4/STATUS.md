# RC4 Expansion transplant attempt: failed/WIP checkpoint

This commit preserves the current source, assets, tests and available build-failure evidence for inspection. It is not a working release or a claim that the latest tree builds. Existing work from multiple contributors is preserved without attributing every change to this session.

The attempted approach transplanted modern Expansion content/battle components into RC4's existing native/vanilla foundation. The observed failures involved incompatible engine APIs, graphics structures, battle-animation fields, text interfaces, species identifiers and script assembly. No successful full combined-game verification is claimed.

Generated executables, ROMs, saves, installed node_modules and toolchain dependencies are excluded. Selected historical compiler logs and test-diff artifacts are under evidence/. They are historical evidence, not a new test run of this checkpoint. All other ignored local build trees remain on the original machine.
