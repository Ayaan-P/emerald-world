# Experimental generated outdoor wilds

This default-off offline prototype extends authored generation beyond caves to a 63×63 outdoor area. The existing bounded room/link compiler produces connected walkable land surrounded by blocked water; the native runtime renders deterministic dirt and tall grass using existing Route 101 tilesets. A separate generated outdoor map uses route music, outdoor behavior and the existing Route 101 wild encounter table. The return tile at 61,61 and the World menu return to the entry location. Normal saves are suppressed in the instance as with generated caves.

Build with `GENERATED_MAP_READY=1 GENERATED_MAP_LARGE=1 GENERATED_MAP_WILDS=1`, then explicitly author a new file using `python3 -m world.author_cave 'islands and grassy paths' --wilds-output wilds.bin` and launch offline with `--generated-map wilds.bin`. The author call sends the description to the configured provider and may incur usage charges. The model proposes bounded geometry, not executable code or newly generated artwork. `EWGMAP06` templates are independently validated before staging and are deliberately rejected by the shared-cave authority. The authority also rejects players or mutable world-mechanic overlays targeting this offline-only map.

This is an outdoor-generation slice, not an integrated multi-region world: it has Route 101 encounters, no authored NPCs, no model-selected wildlife and no multiplayer outdoor instances. The terrain is static existing pixel art, not LLM-generated art. No live provider call, real multiplayer or human playtest has been performed. See exact-head CI for actual native outdoor movement and save-isolation results.
