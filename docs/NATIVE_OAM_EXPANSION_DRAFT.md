# Experimental native OAM expansion

Stacked on #169. This optional PC-only renderer experiment increases the software OAM backing store and render loop from the GBA's 128 entries to 192. The original 128-entry `gMain.oamBuffer` stays in place to preserve `struct Main` layout; an additional 64-entry native-only buffer is copied into the extended portion. Scene resets that use `[0,128)` to mean all OAM also clear the extension. A subsprite group can span entry 127 into entry 128 without writing beyond the original array.

`WORLD_NATIVE_OAM=1` is independent and defaults to 0. With both `WORLD_NATIVE_OAM=1` and `WORLD_EXTENDED_SPRITES=1`, the runtime sprite pool increases from 96 to 127. Sprite IDs remain below 127 because original animation code uses signed bytes. The original GBA path remains at 64 sprites and 128 OAM entries, and `struct Main` and `SaveBlock1` sizes and relevant offsets were compared across portable gate states. The sprite tile VRAM, palette count and affine matrix limits remain unchanged. The larger OAM backing size also affects existing direct OAM clear operations on native builds and needs a full transition audit.

Component tests compile and execute the actual OAM writer and software sprite renderer with disposable stubs. They cover an actual rendered pixel from entry 150, priority against a lower-index sprite, a subsprite group crossing entries 127/128, bounded upload through entry 191, full-range resets, and header/layout checks. The broader inherited capacity fixtures also pass locally. Nonportable header limits remain unchanged. This is not a graphical playthrough or proof that 127 concurrent sprites fit tile/palette memory. No real native build, gameplay, scene transitions, battle animation stress or multiplayer session has been exercised on this revision. CI has a dedicated gate-on build and unchanged-golden headless smoke; inspect its actual result before enabling. Do not integrate or enable without real native rendering, transition, resource exhaustion, old-save and multiplayer acceptance.
