# Generated outdoor guide (offline draft)

This opt-in offline prototype adds one native guide character to a 63×63 generated outdoor area. The model proposes the guide's basic appearance and one or two short literal dialogue lines along with terrain geometry. A deterministic compiler places the guide next to the entrance and reconnects terrain as necessary so the guide cannot block access to the rest of the map. The native client independently validates the geometry and the tightly bounded literal text before staging; text cannot contain engine control codes or executable scripts. The character uses an existing native sprite and a fixed interaction script that displays the validated text.

Build with `GENERATED_MAP_READY=1 GENERATED_MAP_LARGE=1 GENERATED_MAP_WILDS=1 GENERATED_WILDS_GUIDE=1`. To explicitly create a new offline template, use `python3 -m world.author_cave 'a friendly guide near islands' --guided-wilds-output wilds.bin`, then launch offline with `--generated-map wilds.bin`. The author call sends the supplied theme to the configured model provider and may incur usage charges. No live provider request has been made for this draft.

The `EWGMAP07` template is offline-only and rejected by the shared authority. This is one guide with literal dialogue, not a quest system, trainer battle, dynamically generated character artwork, or multiplayer NPC implementation. Ordinary generated wilds remain unchanged. Tests exercise model-wire validation, 60 layouts with connectivity after placing the character, actual native C validation and map-event wiring, and exact loader lengths. See exact-head CI for the real native interaction and save-isolation result.
