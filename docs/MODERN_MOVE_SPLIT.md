# Optional physical/special move split

This source candidate adds a default-off, per-save World-menu switch. Vanilla mode retains type-based physical and special categories. Enabled mode uses per-move categories for all 355 existing native moves, sourced from pokeemerald-expansion-native at bb3fd057061cdd7e6a9e79b76abb41924ee44ecc (four existing Gen 3 names map to their modern spelling equivalents). It does not add the newer National Dex, moves, abilities, or the rest of Expansion's battle engine.

Damage stat choice, type-boosting items, Thick Fat, weather, Flash Fire, burn, Reflect/Light Screen, Hustle, Counter/Mirror Coat tracking, and Fire-move defrost use the chosen category. Standard save behavior applies to the 0x8EB flag; save the game to keep the setting. Check this flag against the combined candidate before integration. Old nonstandard saves may already have this unused bit set.

Native battle OPEN carries a wire-only version bit. Both peers must open with the same split setting, and the setting remains bound across reopens within an activity. Trades retain the previous wire type. Older servers reject modern-mode opens rather than silently starting an incompatible battle; vanilla-mode connections remain unchanged. This is compatibility negotiation, not client attestation against modified clients. Non-native cable/wireless link uses vanilla rules because it has no equivalent negotiation.

Recorded battles do not contain this rules revision. Old recordings are replayed under vanilla rules, and recording new modern-mode battles is disabled to avoid silently replaying them under a different damage model. Existing recordings are not changed.

Focused C tests exercise the real damage calculation and category helpers with isolated stubs. Python tests exercise actual link negotiation and mismatch/abort cases. These do not establish a complete native build, UI behavior, damage interactions across the full battle engine, real co-op/PvP compatibility, native disconnect recovery, or safe play on valuable saves. Before release: validate all category aliases and flags against the combined candidate; exercise representative attacks, items, burn, screens, weather, freeze, Counter/Mirror Coat, AI, abilities, replays, both owner perspectives, mismatch recovery, reconnect, and real separate-player save/reload. Keep the feature unreleased until those checks pass.
