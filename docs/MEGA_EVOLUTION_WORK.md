# Mega Evolution work in progress

This branch is an unfinished implementation, not playable Mega Evolution. It currently contains a battle-only form catalog and ownership/stat calculations for the native species whose listed form abilities and types already exist in the current game. Form stats, types, abilities and stone names come from pokeemerald-expansion-native bb3fd057061cdd7e6a9e79b76abb41924ee44ecc; this is not a wholesale Expansion port. The internal form and stone identifiers are not species or item IDs and must not be written to trainer saves.

The state tracks one use per trainer and a trainer-local slot for an in-battle form, and computes transformed stats from level, IVs, EVs and nature while leaving HP and the underlying party untouched. It is not yet connected to move selection, actual held items or Key Stone acquisition, turn order, ability activation, sprites, switching, private reward restoration, link negotiation, or battle cleanup. Some existing Gen 3 abilities have different modern behavior. These gaps mean no Mega claim or release is appropriate.

The actual next work is to connect selection and battle execution with owner validation and negotiated multiplayer compatibility; add real item/data and licensed or otherwise authorized art; maintain form across switching and revert at battle end/abort without mutating private party species; and expand the catalog alongside the actual newer ability/type implementation. Component tests exercise ownership and stat calculations only, not a native build, co-op runtime, persistence, or gameplay.

The current working code also experiments with appending native-only item IDs 377–393 for stones and a Mega Ring, adds guarded move-choice transport and validates matching battle-rule capabilities. These IDs require a compatibility and migration decision before any real save uses them: older builds and Expansion have different item registries. Placeholder existing item icons are not final art. `MEGA_FEATURE_READY` defaults to 0; move selection cannot activate the unfinished feature. No native game build or real co-op test has been run.
