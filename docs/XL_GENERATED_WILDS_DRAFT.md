# Offline XL generated wilds (experimental)

An agent can compile an inert room-and-link blueprint into a 127×127 outdoor area with `python -m world.xl_wilds examples/agent_xl_wilds.json area.bin`. The compiler and native loader independently check exact dimensions, closed perimeter, entry/exit and connected walkability. The output is a new local file; no provider is contacted and no supplied code runs. The area has 16,129 cells versus 3,969 in the existing 63×63 generated wilds, just over four times the footprint.

The default-off native-only `GENERATED_WORLD_XL=1` build gate expands the field map's transient backing buffer to accommodate the area without changing the trainer save structure or the nonportable build's buffer limit. It uses the existing outdoor art and wild-encounter behavior, moves the exit warp to (125,125), and returns to the original field through the existing Leave action. This is an offline first slice; XL templates are rejected by the shared authority and do not yet carry the authored cast, interaction graph or shared terrain overlays. No new assets, multi-region content, automatic model call or live multiplayer support are included. Tall grass relies on normal encounter behavior and the separate empty-party crash fix.

Tests cover agent blueprint compilation, strict native loader dispatch, native staging/layout and exit-warp relocation, and gate-on/off buffer constants. The gated native CI attempts to walk past the previous 63-cell boundary and return using a disposable save; inspect exact-head CI before saying that playthrough passed. The physical exit warp, live model generation, actual local socket, multiplayer, visual acceptance and cross-platform builds remain untested. Draft stacked on #209; integrate and validate against the current RC6-based candidate separately.
