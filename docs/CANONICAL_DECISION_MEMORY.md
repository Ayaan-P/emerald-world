# Personal consequences of shared conversations

The existing `remember on` option now retains up to 16 completed shared decision
facts per trainer and actor, separated by actual save lineage. No new switch is
required. The memory command discloses the scope and shows current-save facts.

A speaker's selected answer and a listener's own advice are different facts.
Only participants who actually choose or advise are recorded; quiet listeners
are never assigned agreement. Pending advice is bound to the save that gave it,
not the speaker's save or a later active save. Leaving removes pending advice.
Turning memory off clears pending bindings; enabling it later does not backfill.
Forget erases pending and completed facts. The public decision still contains
only the existing anonymous counts, with no trainer or save identity.

The latest four completed facts from this save enter the existing explicitly
requested private reflection summary. They are included in preview and freshness
fingerprinting. A new decision invalidates an old prepared reflection. The host
model may distinguish a listener's suggestion from the speaker's decision, but
must not infer affection, personality or completed activities. Only the actual
acknowledged private native reply becomes the retained tentative perspective.
No response is generated automatically; host worker enablement and the existing
private request remain required. No private facts enter the shared author.

The separate public reaction path can still revise character goals or invoke
supported projects using the anonymous public decision. This update does not
infer that an individual endorsed those projects and does not change story
flags, original battles, inventory, actor movement or the native wire protocol.

Tests exercise two players with opposing answers, real private worker claim and
finish, different native CAST replies and acknowledgments, later save switching,
restart, forget, disabled memory and no backfill. Worker outputs are deterministic
fixtures, not live model behavior. Full field rendering remains native QA work.
