# Experimental generated cave autotiling

`GENERATED_MAP_AUTOTILE=1` is a default-off native experiment for the generated-cave prototype. After a validated wall/floor layout is prepared, a two-pass native autotiler chooses Cave of Origin wall-edge metatiles based on the four neighboring walkable cells. The tile choices follow common patterns observed in the original Cave of Origin maps. Floor uses that tileset's ordinary cave floor, while the original south-facing exit remains intact. This turns abstract generated geometry into a more coherent cave layout using existing art; it does not generate new art or tilesets.

The autotiler runs after either a generated native maze or a staged owner template and before entry. It does not change the wall/floor graph, collision bits, elevation, shared template or cave identity. The chosen floor has the same wild-encounter behavior as the previous floor. The shared-cave prepared-layout comparison recognizes both floor variants. The prototype retains the generated cave's existing default-off feature gate and all parent restrictions.

Tests compile the actual native staging, entry, autotile and prepared-identity functions with disposable engine stubs. They exercise every wall-neighbor mask and 200 styled templates, collision/elevation, entrance/exit, identity mismatches and the real tileset behavior attributes, plus the existing cave and author component suite. A side-by-side offline tile reconstruction was inspected, but it is not a real game screenshot or a substitute for checking tile layering, scrolling, collision, encounters, exits or multiplayer in the native game. The dedicated CI workflow compiles the native generated-cave and autotile gates and runs the standalone headless frame/save smoke; its result must be checked on the exact head. No live model request or multiplayer session is claimed.
