# Autonomous projects with normal-game consequences

An original actor may bind an existing optional native activity to actual
progress in its own immutable shared initiative. The `activity_projects` field
maps `companion` or `scene` to an actor scene ID and shared quality ranges.
The referenced actor turn must actually have committed, not merely have been
authored or have matching initial qualities. The project must belong to this
actor. Private player records are not consulted.

This joins existing systems rather than adding new activities: Steven's original
partner preset for one optional ordinary wild encounter, or the reviewed original
Rydel shared demonstration. An actor can open a project, another actor can choose
whether to contribute, and the committed outcome immediately changes availability
of the real supported invitation without another author turn or player errand.
No fixed arc is shipped. Authors can choose different supported project decisions.

For example, Steven opens a discussion and Wally independently contributes a
perspective. The public shared state now meets Steven's authored conditions for
an optional partner encounter. Players see that invitation at original Steven,
then use the existing explicit native request. This is abstract social activity,
not proof that either actor travelled, trained, or attended an animated meeting.

Current availability appears in the actor's shared project inspection/listing and
original-NPC objective. Admission rechecks actual state. Later choices may close
new invitations; already granted one-shot battles are not revoked mid-battle,
and already running scenes still follow their safe return protocol. Native
campaign, bike service, transport, gifts, saves and normal battles are unchanged.
Existing activities without a project binding preserve their original behavior.

## Author shape

Within an existing canonical action's `changes`, include its immutable
`initiative`, existing `companion` or `scene`, and for example:

    "activity_projects": {
      "companion": {"scene": "contribute", "requires": {"stage": [2, 2]}}
    }

The referenced initiative scene must be an actor-owned turn. It may be assigned
to another existing actor who independently chooses to execute it. All conditions
are public bounded qualities at that scene's place. Ordinary player story turns
cannot impersonate the required actor commitment. Actor-owned world-action
intentions use the existing bounded authority execution and real receipts.
