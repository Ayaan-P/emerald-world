# Large caves with custom wildlife (draft)

This draft combines 63×63 generated cave geometry with a visual profile and a custom 12-slot encounter table. `EWGMAP05` encodes bounded values: one of the existing visual profiles, an encounter rate, 12 canonical native-engine species/level slots, and 3,969 floor/wall cells. The normal native encounter weights and repel logic still apply. This is limited to the current vanilla engine's 386 supported species and does not generate new creature art.

Offline: `python3 -m world.author_cave 'an icy Magikarp cavern' --large-wildlife-output cave.bin`, then launch a native client built with `GENERATED_MAP_READY=1 GENERATED_MAP_LARGE=1 GENERATED_CAVE_PROFILES=1 GENERATED_CAVE_WILDLIFE=1` using `--generated-map cave.bin`. Shared: `python3 -m world.author_cave 'an icy Magikarp cavern' --shared-large-wildlife --admin-socket /path/to/admin.sock`. Both explicit model calls send the theme to the configured provider and may incur charges; model output is bounded data, never code. Existing v1–v4 files remain supported. The authority serves v5 only to CAVE5-capable clients; older clients receive CAVE NONE. A fallback chain permits newer clients to use older hosts.

The identity binds every geometry, profile and wildlife byte. A wildlife-only change forces an in-cave trainer to return before a replacement is staged; reconnecting to the same verified instance is supported. The owner cannot replace an occupied cave. DexNav is disabled while custom wildlife is active. Existing simultaneous entry/return and integration issues remain, and a real two-client playtest and live provider call have not been performed. See exact-head CI for the native offline encounter result.
