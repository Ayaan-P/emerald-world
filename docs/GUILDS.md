# Player guilds

Guilds are optional persistent groups in one World authority. Players can choose WORLD > Guilds to open the existing in-game chat with guild help ready, or open chat directly (T, or Ctrl+T if T is bound). No new game-side wire protocol is required. The server must run the version with guild support. First send `/guild help`; the updated client enables other guild commands only after a private `Guild: protocol 1` reply. On an older server, the help probe may appear in public chat, but the updated client blocks guild chat and board text. This check may need to be repeated after reconnecting or when the capability reply leaves chat history. Older game clients do not have this guard; do not send guild text through them unless you know the server supports guilds. This feature doesn't change Pokémon saves, parties, inventory, battle mechanics or the game engine and is intended to carry over when the Expansion client supports the existing chat protocol.

- `/guild create NAME` creates a guild and makes you its leader.
- `/guild list` (or `/guild list PAGE`) lists public guild names, leaders and membership counts. A player without a guild can request to join with `/guild apply NAME`; the leader reviews `/guild applications` and uses `/guild approve TRAINER` or `/guild reject TRAINER`. Applying grants permission for that leader to add the applicant; an approval cannot move a trainer already in another guild.
- `/guild invite TRAINER` invites an existing trainer in this world. Online invitees see a private message; offline invitees can check `/guild invites`.
- `/guild accept NAME` or `/guild decline NAME` responds to an invitation.
- `/guild info` and `/guild roster` show your own guild. `/guild online` (or `/guild online PAGE`) shows connected members and their recently reported map names, without coordinates; this shares your map name with your guildmates while your field report is fresh. `/guild leave` leaves the guild.
- `/guild kick TRAINER`, `/guild transfer TRAINER` and `/guild disband` are leader actions. A leader must transfer leadership or disband rather than leave.
- `/g MESSAGE` sends chat only to currently connected guild members. Guild chat is session-only; offline players do not receive missed chat.
- A leader can stand at a destination and use `/guild expedition start here 2` to set a shared goal, or use `/guild expedition start Route101 2` with a canonical World map name. The number is how many distinct guild members must visit. Each authenticated member's ready field report at that map counts once. `/guild expedition` shows progress; `/guild expedition cancel` cancels it. Completion is announced privately to online members and persists across server restarts. This is a cooperative visit goal, not proof against modified clients, and it grants no items or rewards.
- For a live gathering, a leader can use `/guild meet start here 2` (or replace `here` with a canonical World map name). The meetup completes only while the requested number of distinct guild members have fresh ready reports on that map at the same time. `/guild meet` shows its status; `/guild meet cancel` cancels it. A meetup and an expedition can be active together. Like expeditions, the reports are client-supplied and grant no rewards.
- Completed expeditions grant 10 guild XP and meetups grant 15, once per objective. Each 100 XP raises the guild level. `/guild info` shows your guild’s progress; `/guild standings` (or `/guild standings PAGE`) shows a world-wide ranking. These are cooperative progression counters, not items or player Pokémon XP. Because position reports come from clients and goals can be repeated, the ranking is not cheat-resistant or a competitive certification.
- `/guild post MESSAGE` adds a persistent note (up to 70 characters) to the guild board. `/guild board` shows the latest eight notes; the server keeps at most 20. Online members receive a private notification. `/guild clear` lets the leader clear the board. Notes are player-authored, untrusted text.
- `/guild help` shows the commands in the game chat. Names use 1–24 letters, digits, underscores or hyphens. A guild can have up to 50 members, and each trainer can be in only one guild per world.

Invitations and membership persist in the world authority's SQLite database; they are not trainer saves. Guild commands are authenticated as the logged-in trainer. There is no automatic battle pairing, shared inventory, bank, shop or item-reward system yet. Expeditions currently cover static maps in the World catalog; generated areas are not included. Player-visible results and invite notices use private chat snapshots; unrelated trainers do not receive them. The server does not provide a delivery guarantee after a connection failure, so check `/guild info` or `/guild invites` before repeating an uncertain command.

Tests use disposable in-memory or temporary databases and in-memory chat handling. They do not establish live two-client or Expansion-client compatibility. No host deployment is included.
