# Agent-painted XL terrain

An agent can compile a 127×127 offline outdoor blueprint plus up to 64 ordered paint rectangles using `python -m world.xl_wilds_palette input.json area.bin`. The bounded palette currently consists of water, grass and tall grass; it is not arbitrary asset generation. Later rectangles override earlier ones. Both the Python compiler and native loader reject protected entrance/exit edits and disconnected walkable geometry. The fixed native renderer maps the inert palette bytes to existing Route 101 tiles; no generated code executes. Tall grass uses the existing encounter system and depends on the separate empty-party fix.

This file format is offline-only, and does not combine with XL characters or interaction graphs yet. Native CI attempts an actual offline walk through painted terrain and checks save isolation. Until CI passes, the in-game result is unverified. This draft stacks #218 and its predecessors; reconciliation with the current integration candidate is separate.
