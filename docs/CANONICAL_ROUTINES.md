# Quiet-world character initiative

The previous cast runtime could react to public events or execute a prewritten
retained task, but could not reconsider its goals while nothing new happened.
An optional routine now gives an already followed actor durable decision windows
through the existing configured author service.

## Behavior

A canonical actor may retain routine {interval_seconds: 60..86400}. Once the host
has enrolled that actor using the existing follow mechanism and the author service
is running, the reaction queue can schedule a quiet-world turn after that interval.
Wally, Briney, Steven and Rydel use the same mechanism with independent intervals.

This is a decision schedule, not a fabricated daily life. The author can choose
one supported next action, retain a concrete task, change a goal, or wait. The
authority still owns actual execution and receipts. Time passage grants no
experience, evolution, friendship, movement, discovery, construction or victory.

The production regression goes from no new player/world event to a scheduled
Rydel decision, a typed retained courtyard intention, then actual autonomous
authority construction and changed walkable geometry. There is no player errand
and no extra model request needed to execute that committed construction.

## Reliability and bounds

Scheduling is durable in the existing host queue. Restart preserves due times
and daily attempt budgets. Overdue work schedules only one turn, never a catch-up
burst. At most eight scheduled attempts per actor/world/UTC day are permitted;
removing/readding a routine cannot reset that budget. Pending work and public
history take precedence. A changed interval starts a fresh full waiting period.

No duplicate pending actor turns are created. Withdrawal/version changes are
rechecked before preparing the author prompt and reject stale decisions. Host
unfollow continues cancelling queued actor work. Disabled routines schedule
nothing. Failed or waiting author turns still consume their scheduled attempt.

Scheduled turns reread exact prior public evidence and remove private player
context just like event-driven turns. The schedule is not itself an event and
cannot satisfy an outcome guard. Actual completed work remains the only basis
for claiming its result.

## Scope

No model worker is started by this feature, no new plugin/authentication access
is created, and no live model has been tested. Hosts must already run/configure
the existing author service and follow the actor. Tests use deterministic author
outputs with the real queue/compiler/authority. /guild cast ACTOR thoughts
discloses the configured quiet-world decision interval and service requirement.

This does not add native walking, canonical relocation, sleep animations or
player-save changes. Original scripts remain intact. App-only candidate, native
pin unchanged; Maya owns integration, rendered QA and release.
