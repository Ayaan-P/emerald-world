# Catalogue-driven canonical campaign observations

One native observer samples the eight badge possession flags and the existing
League-clear flag after normal overworld scripts finish. It does not intercept
nine scenes, hook arbitrary flag writes, read party data, or simulate battles.
A bounded nine-bit `CORE run MILE mask private nonce` packet coalesces unchanged
state. Original scripts, services, rewards, flags and save format are untouched.

Snapshots are private by default. `/history campaign` explains the scope;
`/history campaign on` explicitly enables future anonymous badge/League sharing
for this trainer's current save lineage in this world. `/history campaign off`
stops future publication. The setting is retained by the authority, not global
to other saves/trainers/worlds. The native command reports a request, not confirmed
acceptance. The initial snapshot and achievements already present when enabling
are not public. No per-achievement prompt is required once enabled.

Each newly observed completed bit produces one fixed catalogue claim, such as
“A trainer obtained the Dynamo Badge.” It exposes no trainer name, save ID,
party, battle details or current location. Source explicitly says native client
attestation. It does not claim Rydel won, another trainer progressed, or a specific
battle happened. Badge acquisition and League completion, not arbitrary flags,
are the entire catalogue. A rewind does not retract history or announce the same
milestone twice from one lineage. Off-mode progress becomes the private baseline
when enabling again. Existing public history is not erased by disabling sharing.

The established cast can react through exact native-place interests and choose
new goals/dialogue/other supported actions. No reactions or story arcs are
hardcoded. Tests use actual authenticated authority dispatch and a deterministic
Rydel author fixture, retrieve the changed original-actor response, and verify
no NPC duplication or personal progression changes.

Older clients do not send these packets. Older servers refuse the optional MILE
action; the native adapter stops attempting it for that connection while normal
CORE1 conversation/story behavior remains available. Reconnect retries capability
through the same harmless private snapshot. No chat fallback or public leakage.

Validation includes production C sampling, script-idle gating, coalescing,
on/off commands, old-server refusal, and authority tests for first baseline,
future sharing, rewind, restart, off/re-enable, two saves/trainers, invalid data
and catalogue place matching. Full linked rendering and live model behavior are
not verified here. Pair the draft native/app changes in Maya's integration; the
app engine pin deliberately remains unchanged.
