# Painted XL story persistence

This combines the offline painted XL story world with the opt-in private story journal. POSIX users may run an offline generated map with `--generated-progress on`; the trainer's story state is stored in a private sidecar and restored on re-entry or restart. The 64-entry FIFO is keyed by trainer ID and SHA-256 of the canonical file, including the format magic, palette, characters and rules. Unpainted and painted worlds, and different painted variants, have distinct identities. Journal writes preserve the prior checksummed slot. Windows remains session-only. The trainer save is not changed by this feature.

Local tests exercise production C digests against Python SHA-256, separate palette identities and journal persistence across processes. Native CI attempts an actual offline restart of a painted story while checking that the trainer save is unchanged. Until CI passes, this game path is unverified. The XLP2 sidecar does not migrate or overwrite experimental XLP1 files. This is not multiplayer progression. The draft incorporates the offline progress work from #221 onto #225's painted-world stack; the release candidate still needs separate reconciliation and combined testing.
