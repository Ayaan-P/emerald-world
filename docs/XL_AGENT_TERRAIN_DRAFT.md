# Agent-authored XL terrain draft

This extends durable owner-authored geometry to shared 127×127 wilds. The owner can inspect a shared area and submit or replace up to 512 grass, tall-grass, water or original cells using the existing geometry control. Changes require all trainers to leave. The authority protects entry and exit, validates the entire connected walkable area, commits an overlay revision and forces clients to obtain the new snapshot before re-entry. A `CAVE10T` capability carries chunked overlays; legacy XL clients are refused altered maps. Both authority and native game validate geometry before staging it. The protocol does not execute agent code or invoke a model.

Local tests cover two simulated authority clients, offline persistence, compatibility gating, protected locations, disconnected geometry rejection, compact 512-cell authoring, and production C overlay validation and wire parsing. They do not exercise real sockets, a connected native game, actual multiplayer rendering or live map changes. This draft builds on #211 and its complete predecessor stack, which requires reconciliation with the current integration candidate. It does not change cast or event support for XL areas.
