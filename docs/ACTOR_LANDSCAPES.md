# Agent-authored outdoor layouts

Stack on player-object-use (PR307); native remains PR32 at
30a4fae1b19340225926d350895a30e516615a8c. No native or save-format changes.

`world.create_landscape(label, layout, blueprint)` is discoverable in the normal
actor capability catalog supplied to configured authors. A plan can select:

- `clearings`: seed, landmarks, reservations and optional loops through the
  existing connected route compiler. Reservations remain impassable geometry.
- `connected_shapes`: rooms, links, entrance/exit room and optional deterministic
  rooms/rounded/organic/maze style, seed and corridor width through the existing
  blueprint compiler at 127×127.

Arguments use bounded JSON, not executable code. Both emit validated EWGMAP0A,
with connected ground and the existing protected entrance/exit. Actual outdoor
rendering uses the native Wilds palette. This is not arbitrary biome art, water
simulation, imported region content or a new set of tiles. Existing offline
painted formats are deliberately not advertised as shared-wire support.

The capability activates a **new logical place in the existing shared outdoor
slot**, archives the previous bytes, and commits its real place ID, revision and
receipt atomically. It is not another selectable REGION1 outdoor destination.
Players use the existing shared Wilds entrance with CAVE16 support and XL enabled.
Older clients receive no unsupported map. No automatic travel is performed.

Occupied active slots are refused by the existing authority publication guard.
Active slots with world objects or custody records are also refused: no actor,
prop or resource is silently displaced. Existing original Emerald scenes and
trainer bags/saves are untouched. Following steps can use the returned revision
with `world.populate`; actual actor navigation still requires its real location.
No character is credited with simulated construction or labor.

Component coverage: two actors and two distinct layout generators, archived
identity and restart, real authenticated transfer/ACK and entry, legacy refusal,
occupied/populated refusal, atomic rollback, and the exact paired native C wire
decoder consuming generated bytes. No rendered playtest or live model call.
Maya owns integration and linked-game QA; no merge/release is performed here.
