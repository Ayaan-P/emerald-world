# Experimental generated cave visual biomes

`GENERATED_CAVE_BIOMES=1` is a default-off native experiment that ties a generated cave's existing encounter profile to a matching set of existing cave metatiles. Granite and Victory Road profiles use stone-cave art, the ice profile uses Shoal Cave ice art, and the Meteor profile uses the existing Cave of Origin-inspired cave art (not the separate Meteor Falls tileset). An LLM or person can choose the profile through the preceding cave-authoring work. This does not create new pixel art, tilesets, regions or gameplay rules.

The same validated 31×31 geometry is autotiled with profile-specific wall edges, floor and south-facing exit. It preserves the exact walkable graph, blocked-wall collision and elevation. All chosen floor tiles retain the original cave wild-encounter behavior; all exit tiles retain the south-arrow warp behavior. The existing identity comparison recognizes all floor/exit variants and still checks the profile separately. Profile-aware shared clients use the authority's verified profile; clients without this optional visual gate can render the same walkable world with the previous cave art.

The gate requires `GENERATED_MAP_READY=1 GENERATED_MAP_AUTOTILE=1 GENERATED_CAVE_PROFILES=1` and fails compilation if those prerequisites are missing. Component tests exercise 100 generated layouts across four profiles using the production C autotiler and identity functions, verify collision/elevation and the actual tileset behavior attributes, and check build gates. A local side-by-side reconstruction from existing tiles was inspected; it is not a screenshot from native gameplay.

The dedicated CI workflow builds all four gates and runs the inherited offline native cave and encounter checks plus a native ice-profile encounter. Test-mode telemetry checks the actual in-game floor and exit metatile IDs. Inspect the exact-head CI result. These checks do not establish a human graphical playthrough, actual two-client shared cave session, dynamic art generation, full map/exit acceptance or all transition/recovery cases. All cave features remain experimental.
