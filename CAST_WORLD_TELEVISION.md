# Cast activity reaches ordinary television

This candidate connects two existing features instead of inventing another narrator:
#361's original/generated cooperation and #343's optional world television.

## One connected player journey

An independently authored canonical actor can request supported work from a
world character. The recipient decides whether to accept, runs an existing
capability, and returns the actual successful authority receipt. The requester
can independently publish two short pages referring to those public events.
A player uses an ordinary television, receives its normal programming, and
can choose to watch the attributed world report. The report does not interrupt
play, replace story news, assert a verified player victory, or grant anything.

This is not a fixed Rydel quest. The regression uses Rydel and a researcher to
exercise the general capability: a real temporary Route102 encounter table is
configured before the receipt is delivered and the report published. The
character text remains interpretation, not a validator's guarantee of prose
truth. Reports expire; native screens freeze their copied pages. Only the latest
active bulletin is offered by this existing TV protocol.
